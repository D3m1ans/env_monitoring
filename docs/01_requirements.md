# Цель и требования проекта «AirCheck»

**Цель:** разработать веб-приложение «AirCheck» для мониторинга экологического состояния территории на основе ГИС-технологий, расчёта индекса качества воздуха (AQI) и интеграции с внешним API (OpenWeather).

## Задачи
1. Проанализировать современные методы мониторинга качества окружающей среды.
2. Изучить принципы интеграции данных о загрязнителях с ГИС.
3. Разработать алгоритм расчёта AQI по концентрациям загрязняющих веществ.
4. Реализовать модули сбора, обработки и визуализации данных (Django, PostgreSQL/PostGIS).
5. Обеспечить интерактивное отображение концентраций и AQI (карты, графики, агрегаты).

## Актёры
- **Пользователь** — смотрит качество воздуха по городу, карту, графики, средние значения, скачивает данные.
- **Администратор** — управляет периодическими задачами на сервере и пользователями.

## Контролируемые загрязнители
PM2.5, PM10, CO, NO2, SO2 (O3 — запланирован).

## Итоговый AQI
Максимум из субиндексов по загрязнителям; категории: 0–50 хорошо, 51–100 умеренно, 101–150 вредно для чувствительных групп, 151–200 вредно, 201–300 очень вредно, >300 опасно.
