# Пользовательский интерфейс

Библиотеки: Leaflet.js (карта, подложка OpenStreetMap), Chart.js (графики).

| Страница | URL | Шаблон | Назначение |
|---|---|---|---|
| Качество воздуха в городе | `/air_quality/` | `air_quality.html` | ввод города, текущие концентрации и AQI |
| Карта | `/map/` | `air_quality_map.html` | точки городов, всплывающие данные, фильтр по датам |
| Графики | `/air-quality-graph-page/` | `air_quality_graph.html` | динамика концентраций по городу и периоду |
| Средние значения | `/air-quality-averages-page/` | `air_quality_averages.html` | средние концентрации за период |
| AQI | `/aqi/` | `aqi_page.html` | расчёт AQI по городу и периоду |

JSON-эндпоинты для клиента: `/air-quality-data/`, `/air-quality-graph/`, `/air-quality-averages/`, `/aqi/calculate/`.
